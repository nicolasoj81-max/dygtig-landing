How it works

In the request path, not the invoice

1

Your agent calls out as normal

Your agent calls Claude or OpenAI exactly the way it already does — no code changes to how it prompts or parses responses.

2

Dygtig meters and checks

Dygtig sits in the request path, meters the call, and checks it against the agent's budget before it's allowed through.

3

Under budget goes through. Over budget doesn't.

Under budget: the request goes through untouched. Over budget: it's blocked — before any money is spent.

Most tools tell you what happened after the invoice arrives. Dygtig sits in the actual request path, so it can say no before the call happens.
