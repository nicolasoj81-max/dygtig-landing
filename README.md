# dygtig-landing

Marketing landing page for [Dygtig](https://github.com/nicolasoj81-max/dygtig), a spend-control proxy for AI agents.

Plain static HTML/CSS, single page (`index.html`), no build step, no backend. The "Request Access" buttons are `mailto:` links — no form processing required.

## Local preview

```
python3 -m http.server 8000
```

Then open http://localhost:8000

## Deploy

Static site on Render. See the deployment walkthrough given alongside this repo for exact dashboard steps and custom-domain setup.
